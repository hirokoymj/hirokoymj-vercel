# Welcome to the hirokoymj-vercel Wiki

This is the central hub for documentation about the **hirokoymj-vercel** project.

## Project Overview

**hirokoymj-vercel** is a TypeScript-based application deployed on Vercel that integrates with various Google Cloud Platform (GCP) services and APIs.

**Live Site:** [https://hirokoymj-vercel.vercel.app](https://hirokoymj-vercel.vercel.app)

## Key Technologies

- **Frontend:** React, Redux
- **Language:** TypeScript
- **Deployment:** Vercel
- **APIs:** 
  - Google Maps API
  - Weather API
  - GraphQL Client
  - Google Gemini
- **Infrastructure:** GCP, GitHub Actions CI/CD
